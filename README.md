# Real or AI?

A game in English, Persian, Arabic, Turkish, French and Russian for spotting AI-generated images.

## Development

Requires Node.js 22+.

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:5174/. Changes reload automatically.

```sh
npm test
npm run format:check
```

## Deployment

Push to `main` to check and deploy `public/` to GitHub Pages.
