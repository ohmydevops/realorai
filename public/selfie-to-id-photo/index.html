از یک سلفی ساده، عکس رسمی بساز

با یک سلفی واضح و یک پرامپت انگلیسی، برای پروفایل، رزومه یا کارت داخلی یک عکس مرتب و طبیعی بساز.

کجا می‌تونی ازش استفاده کنی؟

برای پروفایل کاری، رزومه، سایت شخصی یا بعضی کارت‌های داخلی، یک عکس ساده با پس‌زمینهٔ خلوت به کارت میاد. اگر برای مدرک یا جای مشخصی می‌خوای ازش استفاده کنی، کافیه یک بار شرایط عکس همون‌جا رو بخونی.

یک سلفی مناسب بگیر

رو به پنجره بایست و دوربین رو هم‌سطح چشم، کمی دورتر از صورت نگه دار. لنز رو تمیز کن، فیلتر زیبایی و محو کردن پس‌زمینه رو خاموش کن و با سر صاف و حالت صورت طبیعی عکس بگیر. دور سر و شانه جا بذار و فایل اصلی رو نگه دار.

خروجی رو به سلیقه‌ات نزدیک کن

عکس رو به ابزاری بده که ویرایش با عکس مرجع داره. بعد از پرامپت، هر بار فقط یک تغییر بخواه؛ مثلاً «پس‌زمینه سفیدتر بشه» یا «پیراهن سرمه‌ای ساده باشه». اگر زاویه یا صورت درست درنیومده، یک سلفی بهتر بده.

قبل از ذخیره نگاهش کن

خروجی رو کنار عکس اصلی ببین؛ چشم‌ها، مو، گوش‌ها و فرم صورت باید شبیه خودت باشن. لبه‌های مو و لباس و نور رو هم بررسی کن. برای محل استفاده برش بده و با وضوح مناسب ذخیره کن؛ نسخهٔ اصلی رو هم نگه دار.

می‌تونی تصویر هوش مصنوعی رو از عکس واقعی تشخیص بدی؟ بازی ما رو امتحان کن.
